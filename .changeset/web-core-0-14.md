Requires `@a2ui/web_core` 0.14 (was 0.12). Apps that build catalogs with web_core themselves must move to 0.14 too, so both resolve to one copy. Peer ranges now also allow `@wordpress/components` 42–43, `@wordpress/element` 9–10, `@wordpress/i18n` 7 and `@wordpress/icons` 18–19.
